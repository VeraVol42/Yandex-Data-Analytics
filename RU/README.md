## Курс Аналитик Данных от Yandex Practicum


Портфолио проектов, выполненных в рамках курса "Аналитик Данных" от Яндекс Практикум. Программа сочетает теоретические основы статистики, программирование и практические задания для подготовки специалистов по аналитике данных.

🛠 **Основные инструменты и навыки:**
- **Языки и библиотеки:** Python (Pandas, NumPy, SciPy, Statsmodels, Matplotlib, Seaborn, Plotly), SQL  
- **Аналитика:** Метрики, воронки, когортный анализ, юнит-экономика  
- **Эксперименты и гипотезы:** A/B-тестирование, проверка гипотез, приоритизация экспериментов  
- **Презентации и дашборды:** Создание отчетов для поддержки принятия бизнес-решений
