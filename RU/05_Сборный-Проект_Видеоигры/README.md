## 🎮 Исследование рынка видеоигр
 
Проект посвящен исследованию рынка видеоигр, анализу продаж и выявлению ключевых трендов.  

#### 🔍 Основные задачи:  
- Анализ продаж по регионам и платформам  
- Выявление популярных жанров и издателей  
- Оценка динамики рынка по годам  

#### 🛠 Используемые инструменты:  
- **Python**: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`  
- **Jupyter Notebook**
