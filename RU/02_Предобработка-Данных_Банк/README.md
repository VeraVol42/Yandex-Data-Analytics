## 💳 Исследование надежности заемщиков  


Проект посвящен анализу данных заемщиков и построению модели для оценки кредитных рисков.  

#### 🔍 Основные задачи:  
- Исследование факторов, влияющих на вероятность дефолта  
- Подготовка данных для машинного обучения  
- Обучение модели классификации для прогнозирования рисков  

#### 🛠 Используемые инструменты:  
- **Python**: `Pandas`
- **Jupyter Notebook**
