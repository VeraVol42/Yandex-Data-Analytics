## 🏡 Исследование объявлений о продаже квартир

Проект посвящен анализу факторов, влияющих на стоимость недвижимости, и выявлению закономерностей в ценах.  

#### 🔍 Основные задачи:  
- Исследование распределения цен  
- Выявление ключевых факторов, влияющих на стоимость  
- Оценка трендов на рынке недвижимости  

#### 🛠 Используемые инструменты:  
- **Python**: `Pandas`, `Matplotlib`
- **Jupyter Notebook**
