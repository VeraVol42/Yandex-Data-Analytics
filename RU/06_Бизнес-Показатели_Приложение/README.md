## 📱 Анализ бизнес-показателей 
 
Проект посвящен исследованию поведения пользователей мобильного приложения для развлечений. Анализ включает оценку ключевых метрик и эффективности маркетинговых кампаний.  

#### 🔍 Основные задачи:  
- Анализ пользовательского поведения  
- Оценка ключевых метрик приложения (конверсия, удержание)  
- Исследование эффективности маркетинговых кампаний  

#### 🛠 Используемые инструменты:  
- **Python**: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`  
- **Jupyter Notebook**
