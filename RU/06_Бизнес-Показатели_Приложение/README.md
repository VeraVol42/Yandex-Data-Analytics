# 📱 Анализ маркетинговых данных развлекательного приложения

## 📌 Описание  
Проект посвящен анализу маркетинговых данных развлекательного приложения.  
Основные задачи:
- Исследование пользовательской активности и конверсии.
- Оценка эффективности маркетинговых каналов.
- Выявление факторов, влияющих на вовлеченность пользователей.

## 🔍 Методы анализа  
- **Исследовательский анализ данных (EDA)**  
- **Анализ воронки конверсии**  
- **Cравнение маркетинговых каналов**  
- **Статистические тесты (T-тест, χ², Манна-Уитни)**

## 🛠 Используемые библиотеки  
- `Pandas`, `NumPy`, `SciPy`, `Statsmodels`  
- `Matplotlib`, `Seaborn`  

## 📊 Основные выводы  
- Определены **ключевые метрики эффективности** маркетинговых каналов.  
- Выявлены **факторы, влияющие на конверсию**.  
- Даны **рекомендации по оптимизации маркетинговой стратегии**.
