# 📊 A/B Тестирование и Приоритизация Гипотез

## 📌 Описание проекта  
Этот проект посвящен **анализу A/B тестирования и приоритизации бизнес-гипотез** для принятия обоснованных решений. Он включает обработку данных, статистический анализ и оценку результатов эксперимента.

## 🔬 Используемые методы  
- **Анализ данных (EDA)**: предобработка, визуализация, описательная статистика  
- **Приоритизация гипотез**: **ICE** и **RICE** фреймворки  
- **A/B тестирование**:  
  - **Статистические тесты**: t-тест, тест Манна-Уитни  
  - **Анализ коэффициента конверсии и выручки**  
  - **Расчет доверительных интервалов и размера эффекта**  
- **Визуализация данных**: построение графиков для анализа результатов  


## 🛠️ Используемые технологии  
- **Python**: `Pandas`, `NumPy`, `SciPy`, `Statsmodels`  
- **Визуализация**: `Matplotlib`, `Seaborn`  
- **Jupyter Notebook**  


## 🚀 Применение  
- **Оптимизация маркетинговых стратегий** на основе данных  
- **Оценка эффективности изменений в продукте** с помощью контролируемых A/B тестов  
- **Принятие решений на основе статистической значимости**
