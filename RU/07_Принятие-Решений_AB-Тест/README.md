## 🧪 Принятие решений в бизнесе 


Проект посвящен приоритизации гипотез и анализу результатов A/B-тестирования для оптимизации бизнес-метрик.  

#### 🔍 Основные задачи:  
- Оценка гипотез с помощью **ICE** и **RICE**  
- Проверка корректности A/B-теста  
- Анализ статистической значимости различий между группами  

#### 🛠 Используемые инструменты:  
- **Python**: `Pandas`, `NumPy`, `SciPy`, `Matplotlib`, `Seaborn`, `Statsmodels`  
- **Jupyter Notebook**
