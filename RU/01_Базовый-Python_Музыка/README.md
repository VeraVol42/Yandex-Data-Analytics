## 🎵 Вводный проект. Музыка больших городов


Проект посвящен исследованию музыкальных предпочтений пользователей Яндекс.Музыки и анализу жанровых трендов.  

#### 🔍 Основные задачи:  
- Определение самых популярных жанров  
- Сравнение предпочтений пользователей в разных городах  
- Анализ времени прослушивания музыки  

#### 🛠 Используемые инструменты:  
- **Python**: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`  
- **Jupyter Notebook**
