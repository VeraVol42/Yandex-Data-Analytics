## 🛴 Исследование сервиса аренды самокатов GoFast


Этот проект посвящен анализу поведения пользователей сервиса аренды электросамокатов.  

#### 🔍 Основные задачи:  
- Изучение сезонности и паттернов использования  
- Анализ времени и продолжительности поездок  
- Оценка ключевых факторов, влияющих на спрос  

#### 🛠 Используемые инструменты:  
- **Python**: `Pandas`, `NumPy`, `Matplotlib`, `SciPy`  
- **Jupyter Notebook**
