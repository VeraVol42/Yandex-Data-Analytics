## 🎓 Выпускной проект

Данная папка содержит **два независимых проекта**, выполненных в рамках итоговой работы.
В **анализе мобильных приложений** определены ключевые поведенческие паттерны, проведён когортный анализ, сегментация пользователей и визуализация путей.
В **SQL-проекте** решены задачи по извлечению, агрегации и анализу данных, что позволит далее улучшать бизнес-показатели на основе результатов запросов.

---

### 📱 Анализ мобильных приложений

#### 🔍 Основные задачи: 
- Когортный анализ (изучение поведения групп пользователей со временем)
- Сегментация пользователей (деление на группы по активности, регионам и т.д.)
- Визуализация пользовательских путей (диаграмма Санкея)
- Анализ воронки конверсии и ключевых продуктовых метрик

#### 🛠 Используемые инструменты:
- **Python**: (`Pandas`, `NumPy`, `Matplotlib`, `Seaborn`, `Statsmodels`, `datetime`)


#### 📂 Файлы:
