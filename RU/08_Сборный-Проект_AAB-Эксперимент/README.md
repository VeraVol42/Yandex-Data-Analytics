## 📊 Анализ конверсии и A/A/B-тестирование  


Проект посвящен анализу конверсии пользователей и результатам A/A/B-теста для оценки влияния изменений в продукте.  

#### 🔍 Основные задачи:  
- Проверка корректности разбиения трафика в A/A-тесте  
- Оценка влияния изменений в A/B-тесте  
- Анализ статистической значимости различий между группами  

#### 🛠 Используемые инструменты:  
- **Python**: `Pandas`, `NumPy`, `SciPy`, `Matplotlib`, `Seaborn`, `Statsmodels`  
- **Jupyter Notebook**
