# 📊 Анализ конверсии и A/A/B тестирование

### 📌 Описание  
Проект посвящен анализу конверсии пользователей и результатам A/A/B теста.  
Основные задачи:
- Проверка корректности разбиения трафика в A/A тесте.
- Оценка влияния изменений в продукте на ключевые метрики в A/B тесте.

### 🔍 Методы анализа  
- **Исследовательский анализ данных (EDA)**
- **Проверка A/A теста** (отсутствие статистически значимых различий)
- **Оценка результатов A/B теста**:
  - T-тест, тест Манна-Уитни
  - Доверительные интервалы
  - Оценка размера эффекта

### 🛠 Используемые библиотеки  
- `Pandas`, `NumPy`, `SciPy`, `Statsmodels`
- `Matplotlib`, `Seaborn`

### 📊 Основные выводы  
- A/A тест показал **корректное разбиение трафика**.
- В A/B тесте **проверена значимость изменений** в конверсии и среднем чеке.
- Даны **рекомендации** по интерпретации результатов.
