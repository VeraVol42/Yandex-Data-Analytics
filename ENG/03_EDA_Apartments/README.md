## 🏡 Real Estate Listings Analysis

This project focuses on analyzing the factors that influence property prices and identifying patterns in the housing market.

#### 🔍 Key Objectives:  
- Explore the distribution of property prices  
- Identify the main factors affecting property value  
- Evaluate real estate market trends  

#### 🛠 Tools Used:  
- **Python**: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`  
- **Jupyter Notebook**
