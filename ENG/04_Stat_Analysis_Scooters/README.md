## 🛴 GoFast E-Scooter Rental Service Analysis

This project is dedicated to analyzing user behavior in the GoFast electric scooter rental service.

#### 🔍 Key Objectives:  
- Explore seasonality and usage patterns  
- Analyze trip times and durations  
- Identify key factors influencing demand  

#### 🛠 Tools Used:  
- **Python**: `Pandas`, `NumPy`, `Matplotlib`, `SciPy`  
- **Jupyter Notebook**
