## 💳 Borrower Reliability Analysis

This project is dedicated to analyzing borrower data and building a model to assess credit risks.

#### 🔍 Key Objectives:
- Investigate the factors influencing the probability of default  
- Prepare the data for machine learning  
- Train a classification model to predict risks  

#### 🛠 Tools Used:
- **Python**: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`, `Scikit-learn`  
- **Jupyter Notebook**
