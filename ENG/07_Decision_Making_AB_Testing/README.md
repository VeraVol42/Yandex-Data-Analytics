## 🧪 Business Decision Making

This project is dedicated to the prioritization of hypotheses and the analysis of A/B test results for optimizing business metrics.

#### 🔍 Main Tasks:
- Evaluate hypotheses using **ICE** and **RICE**
- Verify the correctness of the A/B test
- Analyze the statistical significance of differences between groups

#### 🛠 Tools Used:
- **Python**: `Pandas`, `NumPy`, `SciPy`, `Matplotlib`, `Seaborn`, `Statsmodels`
- **Jupyter Notebook**
