## 📊 Conversion Analysis and A/A/B Testing  

This project focuses on analyzing user conversion and the results of an A/A/B test to assess the impact of product changes.

#### 🔍 Key Objectives:  
- Validate the correctness of traffic split in the A/A test  
- Assess the effect of changes in the A/B test  
- Analyze the statistical significance of differences between groups  

#### 🛠 Tools Used:  
- **Python**: `Pandas`, `NumPy`, `SciPy`, `Matplotlib`, `Seaborn`, `Statsmodels`  
- **Jupyter Notebook**
