## 📱 Business Metrics Analysis

This project focuses on analyzing user behavior within an entertainment mobile app. The analysis includes evaluating key performance indicators and the effectiveness of marketing campaigns.

#### 🔍 Key Objectives:  
- Analyze user behavior  
- Evaluate key app metrics (conversion, retention)  
- Assess the effectiveness of marketing campaigns  

#### 🛠 Tools Used:  
- **Python**: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`  
- **Jupyter Notebook**
