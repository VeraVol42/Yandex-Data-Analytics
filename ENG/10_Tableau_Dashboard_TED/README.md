## 📊 Building Dashboards in Tableau

This project focuses on exploring TED conference data using **Tableau**. Dashboards were created to analyze the distribution of talks by country, topic, and speaker.

#### 🔹 Key Stages:  
- **Data loading and preprocessing** (merging tables, filtering)  
- **"Talk History" Dashboard** – analysis of geography and yearly trends  
- **"Talk Topics" Dashboard** – topic popularity, laughter and applause analysis  
- **"Speakers" Dashboard** – main areas of expertise, number of talks  
- **Custom Dashboard** – distribution of topics in the "Other" category  

#### 🛠 Tools Used:  
- `Tableau`
