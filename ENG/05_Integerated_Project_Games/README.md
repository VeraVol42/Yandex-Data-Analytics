## 🎮 Video Game Market Analysis

This project focuses on exploring the video game market, analyzing sales, and identifying key trends.

#### 🔍 Key Objectives:  
- Analyze sales by region and platform  
- Identify popular genres and publishers  
- Evaluate market dynamics over the years  

#### 🛠 Tools Used:  
- **Python**: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`  
- **Jupyter Notebook**
