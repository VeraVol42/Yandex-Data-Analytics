## Data Analyst Course by Yandex Practicum

A portfolio of projects completed as part of the "Data Analyst" course from Yandex Practicum. The program combines theoretical foundations of statistics, programming, and hands-on tasks to prepare specialists in data analytics.

🛠 **Core Tools and Skills:**
- **Languages and Libraries:** Python (Pandas, NumPy, SciPy, Statsmodels, Matplotlib, Seaborn, Plotly), SQL  
- **Analytics:** Metrics, funnels, cohort analysis, unit economics  
- **Experiments and Hypotheses:** A/B testing, hypothesis testing, experiment prioritization  
- **Presentations and Dashboards:** Report creation to support business decision-making
