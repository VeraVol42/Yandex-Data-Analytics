## 🎵 Introductory Project. Music of Big Cities

This project is dedicated to studying the musical preferences of Yandex.Music users and analyzing genre trends.

#### 🔍 Main Objectives:
- Identify the most popular genres
- Compare the preferences of users in different cities
- Analyze the timing of music listening

#### 🛠 Tools Used:
- **Python**: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`
- **Jupyter Notebook**
